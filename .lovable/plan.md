# SAP MASTER: what the "Master" dropdown means

## Simple explanation
- You upload one Excel file.
- Every sheet (tab at the bottom of Excel) is saved as one list.
- The "Master" dropdown shows the names of those sheets.
- Choose a sheet name and its data shows in the table below.

Example: an Excel file with tabs "Customer" and "Vendor" will show "Customer" and "Vendor" in the dropdown.

Right now it shows "No masters yet" because no Excel file has been uploaded. Click "Upload Excel" to add one.
